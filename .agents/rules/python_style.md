# Python Coding Style Preferences

When writing Python code for this codebase:

- **Simplest and Most Beginner-Friendly**: Always prefer straightforward, standard solutions suitable for a student learning Python.
- **Built-in Methods**: Rely on standard string and collection methods (`.replace()`, `.split()`, `.join()`, `.count()`, `.strip()`, `.lower()`, `.upper()`, etc.).
- **No Over-Engineering**: Avoid unnecessary list comprehensions, lambda functions, complex nested logic, regex (unless explicitly requested), helper functions, or advanced abstractions.
- **Concise & Direct**: If a task can be solved clearly in 1–3 lines using basic Python, use that approach.
- **No Premature Optimization**: Focus on clarity and readability over micro-optimizations or clever one-liners.
- **Minimal External Libraries**: Do not introduce external libraries when standard Python functionality is sufficient.
